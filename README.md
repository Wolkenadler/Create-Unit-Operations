# Create: Unit Operations (机械动力：工法)

一个以冶金、有机化工、精密制造为核心的机械动力深度工业扩展。**当前处于早期开发阶段。**

## 核心定位
- 不卡原矿，卡加工：前期保留原版生存路线，高级材料必须经过本模组的精加工。
- 工业设备独占：化学反应池、光刻机、区域熔炼炉。
- 软兼容策略：飞控模组等仅作软依赖，检测到即替换配方，未检测到则静默跳过。
